# Tesla Financial Analysis

## Project Overview

This project analyses Tesla's financial statements to understand its financial performance and overall financial position using Microsoft Excel.

## Objectives

* Review financial statement information.
* Analyse revenue and profitability trends.
* Evaluate financial strength and solvency.
* Present financial information in a structured format to support business analysis.

## Tools Used

* Microsoft Excel
* Financial statement analysis
* Financial ratios and solvency analysis

## Project File

The Excel workbook contains the financial statement analysis and supporting calculations.

## Skills Demonstrated

* Financial analysis
* Spreadsheet management
* Financial statement interpretation
* Business insights and reporting

## Disclaimer

This is an educational project prepared for learning and portfolio development. It is not investment advice.
